   write access to `ThomasSioumpalas/new-risk-repo-` (HTTP 403 from the Claude
   GitHub App). All work is committed on the local branch
   `claude/elegant-hamilton-jf1zh0`. To publish it, grant the Claude GitHub App
   access to the repository, then push that branch.
2. **Repository name.** Consider renaming the repository to `sextant-risk`
   (GitHub Settings → General). GitHub redirects the old URL. Then update the
   badge and OCI label URLs in `README.md` and `Dockerfile`.
3. **Exclusions via API.** SoA exclusions are loaded from YAML
   (`exclusions.yaml`) but cannot be managed through the API yet, so the API's
   readiness endpoint does not apply them.
4. **Risk-owner identity binding.** A scenario's `owner` is a role title. It
   is not yet bound to a user account, so any user with the `risk_owner` role
   can accept within their authority.

## How to resume

```bash
uv sync
make check                                   # lint, types, tests
uv run sextant report examples/halcyon --out examples/reports --as-of 2026-09-01
```

The engine version is in `src/sextant/__init__.py` (`ENGINE_VERSION`). Bump it
whenever a change can alter numerical results for the same inputs and seed,
and regenerate the example reports.
